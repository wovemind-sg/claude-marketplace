# Account Warm-up

New WhatsApp number auto-sending messages = top ban cause. WhatsApp trust *history*. Number weeks of human activity survive way better than one paired to Evolution API firing 50 msgs day one. Warm-up mandatory infra, not nicety.

## Before automate anything

1. **Register number on real phone first.** Use WhatsApp app normal few days: profile photo, display name, "about" text. Blank profile only outbound = burner smell.
2. **Real two-way convos.** Message + reply handful real contacts (mutual saving matters — they got you in *their* book too). Inbound replies strong trust signal, pure outbound never gives that.
3. **Age number.** Few days to two weeks light manual use before connect Evolution API. Older + more active = safer.

## Warm-up ramp once connected to Evolution API

Don't jump full volume. Ramp gradual — think week+, not hours. Conservative ramp for new-but-registered number:

| Day | Max outbound / day | Notes |
|-----|--------------------|-------|
| 1–2 | 5–10 | Ideally only replies to inbound messages |
| 3–4 | 10–20 | Mix of replies and a few proactive messages to contacts who know you |
| 5–7 | 20–40 | Still favor conversations that get replies |
| 8–14 | 40–80 | Only now consider larger proactive volume |
| 15+ | Scale slowly | Increase gradually; never double overnight |

Ceilings, not targets. Reply-driven traffic barely counts against you; cold proactive counts heavy. All one-direction outbound day → keep low end.

## Signals that build trust

- **Inbound replies** — strongest positive signal. Warm-up generating real replies age number way faster than blind sending.
- **Being saved as contact** by people you message.
- **Varied activity** — read receipts, reactions, occasional media, not just text blasts.
- **Consistent human-paced daily rhythm** vs huge spike then silence.

## Warm-up for group-heavy use case

Number's job create/manage groups → warm up on messaging first anyway. Then create groups slow (see `references/groups.md`) — new number mass-creating groups + adding participants day one = obvious bot.

## If number is SIM/virtual number

Virtual/VoIP numbers get extra scrutiny, banned easier. Real mobile number if possible. Must use virtual → warm even slower, keep volumes lower long-term.
